- `hero-portrait.jpg`   — Astro Mahri hero portrait (tall/portrait works best)

- `performance.jpg`     — live / editorial shot (wide, full-bleed)

- `lore-con.jpg`        — Lore Con portal visual

the long edge is plenty for web.
